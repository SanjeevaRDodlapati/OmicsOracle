## 🐳 Docker Optimization

### Update Your Dockerfile

**OLD (8GB image):**
```dockerfile
FROM python:3.11
WORKDIR /app
COPY requirements/requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "omics_oracle_v2.api.app:app", "--host", "0.0.0.0"]
```

**NEW (2GB image):**
```dockerfile
FROM python:3.11-slim
WORKDIR /app

# Install only production dependencies
COPY requirements/base.txt .
RUN pip install --no-cache-dir -r base.txt

# Copy application code
COPY omics_oracle_v2/ ./omics_oracle_v2/
COPY config/ ./config/

CMD ["uvicorn", "omics_oracle_v2.api.app:app", "--host", "0.0.0.0", "--port", "8000"]
```

**BEST (1.5GB multi-stage build):**
```dockerfile
# Stage 1: Builder
FROM python:3.11 AS builder
WORKDIR /app
COPY requirements/base.txt .
RUN pip install --user --no-cache-dir -r base.txt

# Stage 2: Runtime
FROM python:3.11-slim
WORKDIR /app

# Copy installed packages
COPY --from=builder /root/.local /root/.local
ENV PATH=/root/.local/bin:$PATH

# Copy application
COPY omics_oracle_v2/ ./omics_oracle_v2/
COPY config/ ./config/

CMD ["uvicorn", "omics_oracle_v2.api.app:app", "--host", "0.0.0.0", "--port", "8000"]
```

## 🔧 Maintenance

### Updating Dependencies

**Add new production dependency:**
```bash
# 1. Add to requirements/base.txt
echo "new-package==1.0.0" >> requirements/base.txt

# 2. Test
pip install -r requirements/base.txt
pytest tests/

# 3. Commit
git add requirements/base.txt
git commit -m "Add new-package for X feature"
```

**Add development tool:**
```bash
# Add to requirements/dev.txt (not base.txt!)
echo "ipdb>=0.13.0" >> requirements/dev.txt
```

### Regenerating Requirements

**If you add new imports:**
```bash
# 1. Re-run pipreqs
pipreqs --force omics_oracle_v2/ --savepath requirements/requirements-production.txt

# 2. Compare with base.txt
diff requirements/base.txt requirements/requirements-production.txt

# 3. Add any missing packages to base.txt
```

### Checking for Unused Packages

```bash
# Use pipdeptree to see dependency tree
pip install pipdeptree
pipdeptree --reverse

# Or use pip-autoremove
pip install pip-autoremove
pip-autoremove <package-name> --list
```

## 🚨 Troubleshooting

### Issue: "ModuleNotFoundError" after switching

**Solution:**
```bash
# The missing package is probably a sub-dependency
# Check what's missing
python -c "import missing_module"

# Find which package provides it
pip search missing_module  # (deprecated, use Google)

# Add to base.txt
echo "missing-package==1.0.0" >> requirements/base.txt
pip install -r requirements/base.txt
```

### Issue: Tests fail after switching

**Solution:**
```bash
# Make sure you're using dev.txt for testing
pip install -r requirements/dev.txt
pytest tests/

# If still failing, check which package is missing
pytest tests/ -v  # Verbose output shows import errors
```

### Issue: Docker build fails

**Solution:**
```bash
# Build with verbose output
docker build -t omicsoracle:debug . --progress=plain

# Check which step fails
# Usually missing system dependencies

# Add to Dockerfile before pip install:
RUN apt-get update && apt-get install -y \
    build-essential \
    libpq-dev  # If PostgreSQL needed
```

## 📚 Additional Resources

### Tools Used

- **pipreqs:** https://github.com/bndr/pipreqs
  - Analyzes imports, generates requirements
  - More accurate than manual analysis

- **pip-tools:** https://github.com/jazzband/pip-tools
  - `pip-compile` locks dependencies
  - `pip-sync` installs exact versions

- **pipdeptree:** https://github.com/tox-dev/pipdeptree
  - Visualizes dependency tree
  - Helps find unused packages

### Best Practices

1. **Separate prod and dev dependencies**
   - Keep `base.txt` minimal
   - Put testing tools in `dev.txt`

2. **Pin versions in production**
   - Use exact versions (`==`) in `base.txt`
   - Use ranges (`>=`) only in `dev.txt`

3. **Regular audits**
   - Re-run `pipreqs` quarterly
   - Check for security updates
   - Remove unused packages

4. **Document why packages exist**
   - Add comments in requirements files
   - Reference the code that uses each package
