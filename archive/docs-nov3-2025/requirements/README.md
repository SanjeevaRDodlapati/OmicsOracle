# Requirements Directory

This directory contains organized dependency files for OmicsOracle v2.

## 📁 File Structure

| File | Purpose | Use When |
|------|---------|----------|
| `base.txt` | **Production dependencies** (25 core packages) | Deploying to Docker, GCP, production |
| `dev.txt` | **Development tools** (testing, linting, formatting) | Local development, CI/CD |
| `requirements.txt` | **Legacy file** (270 packages, full list) | Backward compatibility |
| `requirements-production.txt` | **Auto-generated** (pipreqs output) | Reference only |

## 🚀 Quick Start

### For Production Deployment

```bash
pip install -r requirements/base.txt
```

### For Local Development

```bash
pip install -r requirements/dev.txt
```

### For Testing Current Requirements

```bash
pip install -r requirements/requirements.txt
```

## 🔧 Maintenance

### Adding a New Production Dependency

```bash
# 1. Add to base.txt with version pin
echo "new-package==1.0.0" >> requirements/base.txt

# 2. Test
pip install -r requirements/base.txt
pytest tests/

# 3. Commit
git add requirements/base.txt
git commit -m "Add new-package for X feature"
```

### Adding a Development Tool

```bash
# Add to dev.txt (NOT base.txt)
echo "ipdb>=0.13.0  # Debugging tool" >> requirements/dev.txt
```

### Regenerating from Imports

```bash
# If you add new imports, regenerate requirements
pipreqs --force omics_oracle_v2/ --savepath requirements/requirements-production.txt

# Review and update base.txt with any missing packages
```

## 🐳 Docker Usage

```dockerfile
# Use base.txt for production images
FROM python:3.11-slim
WORKDIR /app
COPY requirements/base.txt .
RUN pip install --no-cache-dir -r base.txt
COPY . .
CMD ["uvicorn", "omics_oracle_v2.api.app:app", "--host", "0.0.0.0"]
```
